# Bounded pipeline baseline: 10M events

Run date: 2026-11-09 (Asia/Singapore)  
Code revision under test: `a1d71c1`  
Command: `equity-matching-engine pipeline-benchmark --events 10000000 --rate 1000000 --capacity 65536 --trials 5 --warmup-events 100000`

## Environment

- CPU: AMD Ryzen 9 9900X, 12 cores / 24 logical processors
- OS: Windows 10 Pro 25H2, build 26200
- Rust: `rustc 1.99.1 (58cf8f9c3 2026-10-13)`, target `x86_64-pc-windows-msvc`
- Build: Cargo release profile, thin LTO, one codegen unit
- Process affinity: logical processors 0 and 1 (Windows affinity mask `3`)
- Offered schedule: 1,000,000 events/s; queue capacity: 65,536
- Measured trials: five, 10,000,000 events each

## Workload and measurement boundary

The producer pre-generates seeded 64-bit payloads and schedules arrivals at a fixed 1M/s rate. It sends through `std::sync::mpsc::sync_channel`; the consumer computes a checksum. Sending blocks when the bounded channel fills. The high-water field tracks outstanding events, including a producer event waiting to enter the queue, so it can exceed the channel's actual occupancy by one. Zero loss requires both all 10,000,000 events completed and the consumer checksum to match.

End-to-end latency runs from each scheduled arrival to consumer completion. The test does not use matching-engine commands, IBKR feed data, disk persistence, or a custom memory layout. It is a baseline queue measurement only.

## Result

All trials completed all 10,000,000 events with matching checksums. Median completed throughput was **999,842.42 events/s**. Median p99 scheduled-arrival-to-completion latency was **275,400 ns (275.4 µs)**, with trial p99 values from 263.8 to 282.7 µs. Outstanding high-water ranged from 724 to 8,143 against the configured capacity of 65,536.

This confirms lossless processing at approximately 1M offered synthetic events/s for the simple blocking-channel/checksum setup. It **fails** the stated p99 goal of less than 10 µs by a wide margin and does not establish optimized queue or memory-layout results. Do not use the third resume bullet as written.
